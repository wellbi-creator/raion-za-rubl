# РАЙОН ЗА РУБЛЬ

Первый веб-прототип изометрической игры.

## Технологии
- HTML5
- CSS3
- JavaScript
- Canvas 2D

## Запуск локально
Откройте `index.html` в браузере или используйте любой статический сервер.

## Публикация через GitHub Pages
1. Создайте публичный GitHub-репозиторий `raion-za-rubl`.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, затем Save.

## Важно
Это ранний клиентский прототип. Сохранение пока работает локально в браузере через localStorage.
Supabase, Telegram-аутентификация и серверная проверка экономики ещё не подключены.
Не используйте клиентское хранение как источник достоверного баланса или наград в публичной игре.
